# Bunly

Anxiety & Panic Companion.

## Layout

```
lib/
  main.dart
  app.dart
  core/theme          # colors and ThemeData
  core/constants
  core/utils
  data/models
  data/repositories
  data/services
  features/home       # empty purple canvas for now
  shared/widgets
assets/
  images/
  icons/
  fonts/
  audio/
  animations/
```

Drop files into those folders as you go. Register new fonts in `pubspec.yaml` when you add them.
